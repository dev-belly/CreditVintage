# CreditVintage 0.4.0

This release adds model-free input checks for label-free monitoring. Earlier
release tags, assets and generated report formats remain available.

## Changes from 0.3.2

- `preflight --as-of YYYY-MM-DD` checks monitoring inputs before model fitting.
  Historical train/calibration populations retain their mature-label, minimum-size
  and both-outcome requirements. The visible current population requires at least
  20 applications and decision-time features, with no current outcome labels.
- Success returns `ready_for_monitoring` JSON with historical/current counts,
  not-yet-visible applications, configured windows and `model_fitted: false`.
  Current outcomes are neither required nor counted. All supplied rows still
  identify the input bundle through its digest and raw counts.
- Preflight and monitoring share the cutoff, current population and label scope;
  preflight and fitting share the historical cohort gates. Too few visible
  current applications now fail before monitoring fits a model.
- Installed-package replay exercises supplied CSVs with all current outcomes
  removed, then checks that actual monitoring uses the same visible population.
- `examples/monitoring_without_outcomes.py` creates an editable synthetic case,
  removes current outcomes by configured decision dates, saves the model-free
  preflight JSON, then fits and verifies the monitor. CI runs the example on
  Linux and Windows. It refuses to overwrite an existing output directory.

The README now identifies both observed public datasets at its entry point.
A [comparison with established tools](../COMPARISON.zh-CN.md) records the existing
capabilities and remaining data, feature-monitoring and adoption gaps.

Without `--as-of`, `preflight` keeps its mature evaluation behavior.
`check-inputs` remains the evaluation-oriented multi-error diagnostic. Existing
input fields, model protocol, dependency pins, scores and report verification
tolerances are unchanged. There is no model or report migration.

This preflight produces no scores or PSI. Input/cohort readiness cannot guarantee
successful fitting, score variation, source authenticity or future model quality.

## Install or upgrade

Use a Python 3.12+ virtual environment:

```text
python -m pip install --upgrade https://github.com/dev-belly/CreditVintage/releases/download/v0.4.0/creditvintage_research-0.4.0-py3-none-any.whl
python -c "from importlib.metadata import version; print(version('creditvintage-research'))"
python -m creditvintage preflight --as-of 2024-10-01
```

The version is `0.4.0`. The built-in synthetic check returns 960 training,
480 calibration and 320 visible current applications, with 160 current
applications not yet visible. It fits no model or writes files. The separately
generated editable starter is smaller; see the
[custom-input walkthrough](../CUSTOM_INPUTS.md) for its counts and supplied-CSV commands.
On Windows replace `python` with `.\.venv\Scripts\python.exe` for an environment
named `.venv`; on Linux/macOS use `.venv/bin/python`.

Publication retains the exact distributions from successful main CI after clean
installation and cross-runtime refitting. The release includes installed-check
evidence, a commit/version manifest and SHA-256 checksums alongside the wheel
and source archive. Existing releases are never replaced.
