# CreditVintage 0.8.2

Ships the recoverable CSV input initialization from [#42](https://github.com/dev-belly/CreditVintage/pull/42)
in a checked, installable wheel.

Use Python 3.12+ in a virtual environment, then run with that environment's
Python. Installation needs internet; initialization and diagnosis work offline.
No Git checkout, PITBridge installation or model fitting is required:

```text
python -m pip install --upgrade https://github.com/dev-belly/CreditVintage/releases/download/v0.8.2/creditvintage_research-0.8.2-py3-none-any.whl
python -c "from importlib.metadata import version; print(version('creditvintage-research'))"
python -m creditvintage init-inputs --out inputs/example-082
python -m creditvintage check-inputs inputs/example-082
```

The version prints `0.8.2`. The new input case has 480 synthetic applications,
1,584 features and 2,880 performance records. Diagnosis reports
`ready_for_evaluation` with `model_fitted: false`. This is the synthetic event
example; it is separate from the observed SBA funding-cohort study.

Previously, an interrupted write could leave three CSVs in the destination;
retrying then refused that incomplete directory. Initialization now prepares
all five files and their hashes in a temporary sibling, then publishes the
complete directory with one rename. Write, hash and publication failures clean
up temporary files and allow a direct retry. Existing paths, including dangling
symlinks, are refused; the destination is checked again before publication.
Parent directories may remain. Initialization does not add a cross-process lock.

The release gate requires the exact installed version and recovery evidence
from a clean wheel environment outside the source trees: interruption at each
of five file writes, hashing and publication; seven successful CLI retries;
model-free readiness; byte-identical successful inputs; and preservation of a
destination that appears during preparation. Recomputed release hashes cannot
substitute for this evidence. Full offline refits and cross-runtime replays
remain part of the release checks.

Successful input bytes, input schema, model protocols, numerical dependencies,
source pins and report formats are unchanged. Existing v0.8.1 assets remain
available; their initializer predates this recovery fix. Generated input cases
remain synthetic and are not evidence of source authenticity or bank adoption.
