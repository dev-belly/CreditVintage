# CreditVintage 0.8.1

Repairs evidence-verification failures and ships the input-boundary and
timestamp-safe integration fixes accumulated since 0.8.0.

```text
python -m pip install --upgrade https://github.com/dev-belly/CreditVintage/releases/download/v0.8.1/creditvintage_research-0.8.1-py3-none-any.whl
python -c "from importlib.metadata import version; print(version('creditvintage-research'))"
python -m creditvintage sba-benchmark --out outputs/sba-credit-081
python -m creditvintage verify-sba outputs/sba-credit-081
```

Version prints `0.8.1`; verification reports 35,000 source records, 10,000 test
loans and 89 recorded 24-month charge-offs. Use Python 3.12+ in a virtual
environment and a new output directory. Installation requires internet;
generation and refitting work offline, without PITBridge or the original
574 MB download.

- Oversized integer claims in SBA summaries are rejected as contract errors,
  including after an edited file's digest is recomputed. `verify-sba` returns
  exit 2 with a diagnostic instead of an `OverflowError` traceback.
- SBA and card evidence ZIPs with broken DEFLATE streams return exit 2.
  Card verification also handles unsupported compression/encryption errors
  and checks each member's declared size before reading it. Inventory and
  exact-content checks still apply; failed verification does not rewrite files.
- Positive principal cents must fit signed int64 while remaining exact above
  `2^53`. Oversized event values and configuration fractions fail before
  readiness checks or fitting. CSV diagnostics retain the file and line.
- Optional lineage uses PITBridge commit
  `219e58a7c2acc4a3fcd4f7ffdb68ba8eef0564f0`, which rejects timestamps finer
  than a microsecond instead of silently rounding them at a decision cutoff.
  The standalone SBA and UCI paths do not install this optional dependency.

Source regressions cover malformed summaries, compressed streams, unsupported
compression and size mismatches. The installed-wheel gate additionally checks
rehashed false/oversized SBA metrics and a damaged ZIP, alongside full normal
workflows, offline refitting and cross-platform replay.

Models, source/protocol pins, targets and report formats are unchanged. Existing
valid 0.8.0 SBA evidence still verifies. The SBA study remains retrospective:
historical first-publication and feature-revision records are absent. Consistent
evidence is not proof of source authenticity, independent adoption or lending
performance.
