# CreditVintage 0.8.0

Adds observed SBA funding-cohort validation, a pinned raw-source converter and
portable evidence that refits offline. Existing synthetic event, UCI, quality
and policy contracts remain compatible; numerical dependencies remain pinned.

```text
python -m pip install --upgrade https://github.com/dev-belly/CreditVintage/releases/download/v0.8.0/creditvintage_research-0.8.0-py3-none-any.whl
python -c "from importlib.metadata import version; print(version('creditvintage-research'))"
python -m creditvintage sba-benchmark --out outputs/sba-credit-080
python -m creditvintage verify-sba outputs/sba-credit-080
```

Version prints `0.8.0`; verification reports 35,000 frozen source records,
10,000 test loans and 89 recorded 24-month charge-offs. Use a new destination
on repeat. PITBridge and the 574 MB original download are not required.

The two official CSVs contain 1,236,084 records. Fixed date windows retain
20,000 train / 5,000 calibration / 10,000 test loans after recorded-identity
grouping and outcome-independent hash sampling. Earlier outcome horizons end
before the next stage starts. Four approval inputs, training-only preprocessing
and separate isotonic calibration avoid test fitting. Calibration's reduced
ranking performance remains visible alongside its improved Brier.

All scores, same-budget queues, year slices and 300 paired month-bootstrap
replicates are retained. Verification refits from pinned source bytes and
checks the entire ZIP, rather than trusting file hashes. The release gate
requires installed SBA refitting and rejection of a rehashed fabricated metric.
The Linux evidence ZIP is also replayed on Windows and another Python version.

This is a retrospective final-snapshot study. First-publication times and
historical feature revisions are absent. Recorded 24-month SBA charge-off
is distinct from synthetic 180-day delinquency and UCI native labels. No
historical public-availability, deployment, savings or independent-use claim.

Original software and UCI dataset terms are preserved.
