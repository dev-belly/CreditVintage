# Support for CreditVintage

Choose the guide for the failing workflow: [custom CSV inputs](docs/CUSTOM_INPUTS.md), [feature quality](docs/FEATURE_QUALITY.md), [review workflow](docs/REVIEW_WORKFLOW.md) or [source lineage](docs/LINEAGE.md). Python 3.12+ is required. The package pins numerical dependencies because published evidence is replayed.

Use the existing [SBA reproduction or trial-feedback forms](https://github.com/dev-belly/CreditVintage/issues/new/choose), or the general bug form for other failures. Include the package version/commit, OS/Python, exact command, cutoff and smallest synthetic input that reproduces the result. Distinguish label-free monitoring from evaluation with mature outcomes; a missing or immature outcome is not a nondefault label.

For review problems, describe same-ID retries, competing operations and evidence references without uploading private material. For optional lineage failures, identify the PITBridge revision; ordinary evaluation and monitoring do not require that integration. Preserve file manifests and the verifier error, but remove private rows rather than publishing a complete evidence bundle.

[CONTRIBUTING.md](CONTRIBUTING.md) lists targeted checks, full CI expectations and installed-package replay. Use [SECURITY.md](SECURITY.md) for a suspected vulnerability. Dataset attribution remains governed by the notices linked in [the license section](README.md#license).
